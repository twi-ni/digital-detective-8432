# Mission 7 - How Computers Communicate

## Objective

The aim of this mission was to understand how computers communicate with each other through networks and what happens when we open a website.

## Work Completed

### Task 7.1 - Explain Network Concepts
Learned about basic networking concepts like LAN, MAN, WAN, DNS, Router, Protocol, Packet Switching and Client-Server. I also wrote simple explanations and examples for each concept.

### Task 7.2 - Observe Network Information
Used Terminal commands to check internet connectivity and find the IP address of a website.

Commands used:
- `ping -c 4 google.com` - Checks if my computer can reach Google's website.
- `nslookup google.com` - Finds the IP address linked to Google's website.

### Task 7.3 - What Happens When You Open a Website?
Explained the steps that happen when we enter a website address in a browser, from the DNS lookup to the webpage finally appearing on the screen.

## Commands and Tools Used

- `ping` - To check network connectivity.
- `nslookup` - To look up a website's IP address.
- Terminal - To run the network commands.
- Markdown - To write and organise the task explanations.

## What I Learned

Through this mission, I got a better idea of how computers communicate over networks. I learned about different types of networks, how DNS works and how routers help transfer data.
I also understood that opening a website involves multiple steps in the background, even though it looks like a simple process from our side.

## Difficulties Faced

At first, some networking terms were confusing, especially DNS and packet switching.

## How I Solved Them

I went through each concept one by one and used simple examples to understand them better. Running the commands in Terminal also helped me understand how network lookups and connectivity checks work.
