
# Mission 3 - Understand the Operating System

## 1. Task
In this mission, I had to learn more about how an operating system works and what it does in a computer. I explored running programs, storage, files and permissions, and also had to make sure I didn't share any personal information.

## 2. Work completed
Completed Tasks 3.1 to 3.4 in `mission-3-task.md`.
- Task 3.1: Checked my macOS details, user account, storage and running processes using Terminal.
- Task 3.2: Learned what processes and PIDs mean and looked at some examples.
- Task 3.3: Learned about absolute and relative paths and checked file permissions.
- Task 3.4: Learned about six things an operating system does and understood them with everyday examples.

## 3. Commands / Tools used
- `sw_vers`, `uname -m` - Used these to check my macOS version and processor details.
- `whoami` - Checked which user account I was using.
- `df -h /` - Checked the storage used and the free space available.
- `ps aux | head -n 10` - Used this to see some of the processes running on my Mac.
- `pwd`, `cd`, `ls -l` - Used these to check folder locations, move between folders and see file permissions.
- Git (`git status`, `git add`, `git commit`, `git push`) - Used these to commit my work and push it to GitHub.

## 4. What I understood
I learned that the operating system is what helps the hardware and the applications work together. It takes care of things like running programs, memory, files and permissions. I also learned that every running process has a PID which helps the OS identify it. Before this mission, I didn't really know how many things the OS manages in the background while we use our computers.
