
# Mission 2 - Become Comfortable with the Terminal

## 1. Task
The aim of this mission was to learn how to use the Terminal, move between folders, create and manage files, and understand some useful commands. I also learned about flags, pipes and package managers like Homebrew.

## 2. Work completed
Completed all four tasks in `mission-2-task.md` and tried the commands in the `terminal-practice/` folder.

- Task 2.1: Tried basic Terminal commands and noted down what each one did.
- Task 2.2: Created a text file, added some text to it, made changes and created a backup copy.
- Task 2.3: Tried `ls` and `ls -lah` and also used a pipe to show only a few lines.
- Task 2.4: Checked if Homebrew was installed and learned what package managers are used for.

## 3. Commands / Tools used
- `pwd`, `ls`, `ls -l`, `ls -lah`, `cd` - Used these to check my location and move around folders.
- `mkdir`, `touch`, `cp`, `mv`, `cat` - Used these to create, copy, rename and read files.
- `echo`, `>`, `>>` - Used these to write text into files and add more text without deleting the old content.
- `|` and `head -n 5` - Used these to pass the output of one command to another.
- `brew --version` - Used this to check the Homebrew version.
- Git (`git status`, `git add`, `git commit`, `git push`) - Used these to save my changes and push them to GitHub.

## 4. What I understood
I learned that the Terminal can be used to do a lot of things that we normally do using folders and files on the screen. I also understood why `>` and `>>` are different, since one replaces the old content while the other adds to it. Flags help show extra information and pipes are useful when I don't want the full output of a command. I also learned that Homebrew makes it easier to install and manage software on macOS.
