## 4.My understanding
A computer basically follows the IPOS cycle to get things done. For example, when I type an essay, the keyboard takes my input, the CPU and memory process it, the monitor shows what I've typed and the SSD saves the file. I also learned how hardware and software work together with operating systems, applications and utilities helping the computer perform different tasks. Even everyday things like ATMs and traffic signals follow the same basic input and output process.
