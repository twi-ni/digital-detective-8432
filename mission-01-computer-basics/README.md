## 4. What I understood
I learned that a computer uses the IPOS cycle to complete tasks. For example, when I type an essay, the keyboard takes the input, the CPU processes it, the monitor shows it and the SSD stores the file. I also understood the difference between hardware and software and how both are needed for a computer to work. Even things like ATMs and traffic signals use inputs and outputs to do their work.
