
# Mission 5 – Numbers and Data

## Task 
The objective of this mission was to understand how computers represent numbers and text using different number systems like decimal, binary and hexadecimal. I also had to practise converting numbers manually, verify the answers using Python and build a small number converter program.

## Work Completed
- Converted decimal numbers into binary.
- Converted binary numbers into decimal.
- Converted hexadecimal numbers into decimal.
- Converted binary numbers into hexadecimal.
- Verified the manual conversions using Python's built-in functions.
- Created a Python program that takes a decimal number as input and displays its binary and hexadecimal forms.
- Tested the converter with different numbers.
- Learned about ASCII and Unicode text encoding.

## Commands / Tools Used
- **VS Code** – To write and edit the files.
- **Terminal** – To run the Python program.
- `python3 number_converter.py` – To execute the converter.
- Python functions used: `input()`, `int()`, `bin()`, `hex()` and `print()`.

## What I Understood
I understood how decimal, binary and hexadecimal number systems work and how to convert values between them. I also learned how Python can make these conversions easier using built-in functions. The mission helped me understand that computers store text using encoding standards like ASCII and Unicode.

## Difficulties Faced
Initially, understanding how to convert numbers between different bases was a little confusing. I also had to understand why Python displays prefixes like `0b` and `0x` before binary and hexadecimal values.

## How I Solved Them
I worked through the conversions step by step and then checked my answers using Python. I also used `[2:]` in my converter program to remove the prefixes from the displayed results.
