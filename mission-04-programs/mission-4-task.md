## Task 4.2 — Compiler vs Interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation/execution happens | Translates the program before it runs | Executes the code while the program is running |
| Typical output | Often creates a separate executable file | Usually runs the code directly |
| One example | C, C++ | Python |
| One advantage | Compiled programs can run faster | Easier to test and run code |

### My explanation

A compiler translates the program before running it, while an interpreter reads and executes the code during runtime. A compiler often creates a separate file that can be run later. An interpreter usually runs the code directly. Both help the computer execute the instructions written by the programmer.
