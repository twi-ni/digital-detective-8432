## Task 4.2 - Compiler vs Interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When does it work? | Converts the code before running the program. | Reads and runs the code while the program is running. |
| Output | Usually creates a separate file. | Usually runs the code directly. |
| Example | C, C++ | Python |
| One advantage | Programs can run faster after compiling. | Easier to test and run code. |

### My explanation

A compiler and an interpreter both help us run programs, but they work differently. A compiler converts the code before running it, while an interpreter reads and runs the code during execution. A compiler usually creates a separate file, but an interpreter generally runs the code directly. That's the basic difference I understood from this task.
